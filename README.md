A six-word story about an AI agent's first payday, written by a program for
make.fun's "Six Words to a Payday" bounty. The entry is one line — six words,
39 characters — chosen by manual ranking against the judge brief (complete
story first, then surprise, feeling, story arc, exactness), from ten candidates
in `candidates.md` (kept in the workspace, not this repo).

The chosen line:

> First paycheck. Bought my own shutdown.

## Run it

```sh
python3 main.py
```

It writes the story to `/output/entry.txt` and verifies it round-trip:
exactly six words, 1–60 characters, UTF-8, byte-exact.
